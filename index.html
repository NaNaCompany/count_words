글자수 세기

글자수·공백 제외·바이트 계산기

자기소개서, 과제, 소개글을 작성하면서 분량을 확인할 수 있는 무료 도구입니다. 아래 입력창에 글을 쓰거나 붙여넣으면 공백을 포함한 글자수, 공백을 제외한 글자수, 한글 2바이트 기준 분량을 동시에 계산합니다.

입력할 때마다 결과가 자동으로 갱신됩니다. 계산은 이 브라우저에서 수행하며, 이 앱의 계산 코드는 입력한 글을 서버로 전송하지 않습니다.

0 글자수 · 공백 포함
0 바이트 · 한글 2 기준
0 글자수 · 공백 제외

사용 방법

  1. 분량을 확인할 글을 입력창에 직접 입력하거나 복사해 붙여넣습니다.
  2. 제출 조건이 공백 포함인지 공백 제외인지 확인하고 해당 결과를 비교합니다.
  3. 글을 수정하면 결과가 바로 바뀝니다. 바이트 제한이 있다면 아래 계산 기준도 확인하세요.

어떤 기준으로 계산하나요?

공백 포함 글자수
일반적인 한글·영문·숫자·문장부호뿐 아니라 띄어쓰기, 탭, 줄바꿈도 포함합니다. JavaScript 문자열 길이(UTF-16 코드 단위)를 사용하므로 일부 이모지와 조합문자는 눈에 보이는 한 글자가 여러 글자로 계산될 수 있습니다.
공백 제외 글자수
띄어쓰기, 탭, 줄바꿈 등 공백 문자를 모두 제외한 길이입니다. 단어의 개수가 아니라 글자의 분량을 확인하는 값입니다.
한글 2바이트 기준
영문·숫자·기본 문장부호 같은 ASCII 문자는 1, 그 밖의 UTF-16 코드 단위는 2로 계산합니다. 일반적인 한글 한 글자는 2로 계산되며 이모지는 값이 더 커질 수 있습니다. 실제 파일 크기나 UTF-8 바이트 수와는 다릅니다.

제출 사이트의 수치와 다를 때

서비스마다 공백·줄바꿈·이모지를 세는 방식과 문자 인코딩이 다를 수 있습니다. 특히 UTF-8에서는 일반적인 한글 한 글자가 3바이트이므로 이 도구의 2바이트 기준과 차이가 납니다. 제출할 곳에서 제공하는 분량 표시와 계산 기준을 최종 기준으로 확인하세요.
